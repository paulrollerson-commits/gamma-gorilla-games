# Gamma Gorilla Games

Two original HTML5 browser mini-games. Each folder is a complete, self-contained game: open `index.html` (or serve the folder) with no build step and no external libraries.

- **Sky Parcel** — one-screen platformer-runner. Deliver letters across floating docks.
- **Nova Drift** — arcade dodge-and-shoot. Weave debris and claim energy cores.

Controls are keyboard and touch. Scores and mute settings save in the browser.

Made by Gamma Gorilla Productions.
